# JoJo Action Demo — experimento opcional

Execute a partir da raiz do projeto:

```bash
python experiments/jojo_action_demo/main.py
```

Controles: setas esquerda/direita para andar, seta para cima para pular, seta para baixo para agachar, Espaço para atacar e Esc para sair. O loop usa 60 FPS com delta time; música e som de ataque são opcionais.

Esta demo não é necessária para iniciar o JoJo-OS e ainda não implementa combate completo. Os assets precisam ser avaliados quanto a direitos/licenças antes de distribuição pública.
